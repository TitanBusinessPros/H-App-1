Publish Your Free Website

This builder and the finished trivia website are free. To publish your site with GitHub Pages:

  1. Click Export as HTML File to download your finished website as index.html.
  2. Create a public repository on GitHub Free and upload index.html to the repository's main folder.
  3. Open the repository's Settings, choose Pages, and set the source to the main branch and /(root).
  4. Save the Pages settings. GitHub will publish your free website at the URL shown in the Pages settings.
